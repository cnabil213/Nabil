## 1. Setup caméras

### Nombre de caméras

Pour un rendu professionnel (référence visée : **TARMAC – RapOji**) → **3 caméras** :

| Caméra | Cadrage |
| :--- | :--- |
| **Cam 1** | Plan large |
| **Cam 2** | Face invité A |
| **Cam 3** | Face invité B / animateur |

### Caméras recommandées (budget raisonnable)

| Modèle | Gamme de prix |
| :--- | :--- |
| Canon M50 | 500 € – 900 € |
| Sony ZV-1 | 500 € – 900 € |
| Sony A6100 | 500 € – 900 € |

Toutes dans un bon rapport qualité / prix, **900 € max**.

### Cartes d'acquisition

Pour relier les caméras au PC : **Elgato Cam Link** (ou équivalent), une par caméra.

## 2. PC & logiciel

- PC portable ou fixe
- **OBS Studio**, qui permet de :
  - ✔ enregistrer plusieurs angles
  - ✔ synchroniser audio + vidéo
  - ✔ switcher en direct
  - ✔ sauvegarder le tout sans montage complexe

## 4. Workflow de tournage

1. Installer les caméras
2. Brancher au PC via Cam Link
3. Récupérer la sortie audio de la table du studio
4. Tout mettre dans OBS
5. **Vérifier la synchro audio / vidéo**
6. Lancer l'enregistrement multi-caméras
7. Exporter
8. Monter (si nécessaire)
9. Sortie TikTok / YouTube / Instagram

> ⚠️ L'étape 5 est celle qui coûte le plus cher si elle est sautée : une désynchro
> non détectée sur le plateau, c'est la session entière à rattraper au montage.

## 6. Les deux scénarios budgétaires

### ✅ Scénario 1 — « Studio Rental » *(recommandé)*

Louer un studio **tout équipé** (ex. Ambiorix).

- **Coût : ~150 € par session**
- Une session = **4 épisodes** tournés à la suite
- Zéro investissement matériel, zéro stockage, zéro maintenance

> C'est le scénario recommandé pour démarrer : il permet de tester le format sans
> immobiliser de capital. Le vrai coût d'un tournage devient le temps de préparation,
> pas le matériel.

### Scénario 2 — « Home Studio Pro »

Investissement initial : **~2 500 €**

| Poste | Matériel |
| :--- | :--- |
| **Caméra** | Sony ZV-E10 |
| **Lumière** | Godox / tubes LED |
| **Audio** | Rode Wireless PRO |

À n'envisager que quand la cadence de tournage rend la location plus chère que
l'achat.
